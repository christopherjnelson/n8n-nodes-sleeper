# 0.2.0 “NFL Season Ready” plan

Version 0.2.0 expands the package with credential-free NFL automation built only on Sleeper's
documented public HTTP API. Existing raw operations remain available and unchanged.

## Phase 1 — Sleeper Trigger

The Sleeper Trigger polls documented public endpoints; Sleeper does not document backend webhook
subscriptions for these events.

- Draft Pick Made
- Transaction Created or Updated
- League Status Changed
- NFL Week Changed

Phase 1A implements only **Draft Pick Made**. The other polling events remain future work.

## Phase 2 — Current-context conveniences

- Matchup using current NFL week
- Transactions using current NFL week
- User leagues/drafts using current league season

Each convenience operation makes an additional NFL-state request to determine the current context
before it makes its resource request. These operations will supplement, not replace, the existing
raw operations.

## Phase 3 — Transparent composite operations

- League Standings
- Matchup Scoreboard
- Roster Directory
- Draft Board

Each composite operation will disclose every component API request it makes and will supplement,
not replace, the existing raw operations.

## Phase 4 — Public examples

- Live draft announcer
- Transaction feed
- Weekly scoreboard
- Standings snapshot
- NFL week-change automation

## Non-goals

- Writes or lineup changes
- Adds, drops, or trades initiated through the node
- True Sleeper backend webhooks
- Private account access
- Chat
- Sleeper Picks or paid contests
- Undocumented APIs
- Player-map fetches on every event
- Sports other than NFL in 0.2.0
