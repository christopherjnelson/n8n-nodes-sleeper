# Sleeper API matrix

Baseline: Sleeper public API v1 documentation and representative public responses reviewed September 2026. Public API access is credential-free; edition is “Public” throughout. All operations are read-only and non-destructive.

| Resource / operation         | Automation value               | Method / API                                   | Style / evidence                   | Visible controls / minimum state                   | Output             | Contract / human docs      | Observed behavior              | Test tiers / uncertainty                |
| ---------------------------- | ------------------------------ | ---------------------------------------------- | ---------------------------------- | -------------------------------------------------- | ------------------ | -------------------------- | ------------------------------ | --------------------------------------- |
| Avatar / Get URL             | Validate a reusable avatar URL | `HEAD` CDN `/avatars[/thumbs]/{id}`            | Declarative; route + hook contract | ID, size / both valid                              | URL metadata       | CDN pattern / node docs    | HEAD validates existence       | Unit + package; CDN availability varies |
| Draft / Get                  | Retrieve draft metadata        | `GET /draft/{id}`                              | Declarative; route contract        | Draft ID / nonblank                                | Object             | Public API / matrix        | Raw object                     | Unit; live ID varies                    |

| Sport / Get State            | Drive season/week automation   | `GET /state/{sport}`                           | Declarative                        | NFL / allowed value                                | Object             | Public API / trigger docs  | Current state fields           | Unit + trigger regression; volatile     |

The Sleeper Trigger is deliberately programmatic: polling validates responses and compares them with persisted workflow state to suppress historical replay. Opaque identifiers are trimmed and percent-encoded individually. Tests are deterministic and structural; representative live checks do not guarantee future availability or schema stability.
